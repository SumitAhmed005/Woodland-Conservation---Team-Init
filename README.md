## Repository Structure
- `docs/` – SDP, style guidelines and meeting minutes
- `src/pages/` – one file per site page
- `src/components/` – navigation, audio buttons, language switcher, appearance toggle
- `src/styles/` – dark/light mode and shared styles
- `src/locales/` – text content per language (`en`, `fr`, `mic` for Mi'kmaw)
- `assets/images/` – images, shared across all languages
- `assets/audio/` – narration and image-description audio per language
